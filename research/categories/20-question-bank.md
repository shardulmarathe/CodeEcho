# Category 20 — Question bank (curated vs generated)

**Evidence:** [`../notes/20-question-bank.md`](../notes/20-question-bank.md)

## Bottom line

**Evidence favors curated + labeled-generation hybrids** over silently serving raw live-gen banks as if they were calibrated. Curated offline mock bank ≈ pretest-grade content; live LLM generation ≈ uncalibrated drafts. **Never silently swap** them—different instruments. Label **static mock bank** vs **generated this session — uncalibrated**. Calibrate seniority/bucket with a blueprint + filters, not a one-shot “senior” prompt.

## Recommended CodeEcho actions

1. Tag every question with `source: mock|generated|pasted` in API + UI chrome.
2. Keep mock bank for offline/429; never present as live gen.
3. Longer-term: blueprint + SME/filter loop before promoting gens to “bank.”
4. Document version of generators for consistency claims.
